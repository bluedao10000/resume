# 套餐与用量

更新：2026-11-14。USD 月订阅；本页描述已实现的计费首版。

| 套餐 | 月价 |    每期额度 |
| ---- | ---: | ----------: |
| Free |   $0 |  10 credits |
| Plus |  $10 | 125 credits |
| Pro  |  $50 | 625 credits |

额度是 Folio 的产品选择，集中配置在 `.env`，不是 OpenAI 或 Anthropic 对其订阅所作的配额承诺。三档共用简历管理与 Agent 功能，区别是用量。演示模式不调用模型、不扣额度。Free 按 UTC 自然月重置；付费套餐按 Stripe 订阅周期重置。未用额度不结转，不自动收取超额费用。没有年度订阅、充值、超额账单或团队席位。

## Token 规则

当前配置模型为 `gpt-6.1-sol`，采用 Standard 档参考费率。每百万 Token 消耗：

| 类别         | credits |
| ------------ | ------: |
| 非缓存输入   |      50 |
| 缓存读取     |     2.5 |
| 缓存写入     |    62.5 |
| 输出，含推理 |     250 |

按 pi 归一化后的互斥类别结算。输入包括本轮文字、历史上下文、简历来源、系统指令及工具定义；缓存命中部分走缓存费率，不能再次计入普通输入。推理已包含在输出，不重复扣减。例：1,000 普通输入 + 100 输出 + 100 缓存读取 = **0.07525 credits**。

请求前预留额度，结束后释放未使用部分。预留不是实际 Token，也不是扣费结果。若余额不足以覆盖最小输出预算，Agent 返回额度不足并保留当前简历。停止或失败时，已由模型报告的有效用量仍会结算；没有报告的用量不推算收费。刷新或重发同一请求标识不重复扣减，另发一条消息属于新请求。

参考规则检索于 **2026-11-14**：

- OpenAI Codex 官方 Standard `GPT-6.1 Sol` 的输入 / 缓存输入 / 输出 credits 为每百万 50 / 2.5 / 250。Codex credits 没有独立缓存写入收费项。来源：<https://developers.openai.com/codex/pricing>（当前重定向至 <https://learn.chatgpt.com/docs/pricing>）。
- 同模型 OpenAI API Standard 短上下文价为输入 $2、缓存输入 $0.10、输出 $10 / 百万 Token；30 分钟缓存写入 $2.50、12 小时 $5。Folio 的缓存写入 62.5 credits 是按当前 API 30 分钟写入价换算的产品费率，不能称为 Codex credits 规则。来源：<https://developers.openai.com/api/docs/pricing>。
- Claude 官方按输入、输出、缓存写入和缓存读取区分费用，例如 Sonnet 5.5 为输入 $2、输出 $10、5 分钟缓存写入 $2.50、1 小时写入 $4、读取 $0.10 / 百万 Token。Folio 参考其分类方式；没有将 Claude 价格套到当前 OpenAI 模型上。来源：<https://platform.claude.com/docs/en/about-claude/pricing>。
- Codex / Claude 订阅用量会受上下文、模型、工具、任务复杂度等影响，不能将订阅金额简单等价为固定消息数。来源：<https://support.claude.com/en/articles/9797557-usage-limit-best-practices>。

这些来源是当前费率的依据；官方未来变更不会自动修改已预留请求的费率。更换模型时必须同时配置匹配的 `BILLING_MODEL`、费率和版本。

## 订阅体验

侧栏“套餐与用量”集中展示套餐、余额、预留、重置日期及分类 Token 用量，不占用聊天区高度。升级跳转 Stripe Checkout；已有订阅通过 Stripe Portal 管理与查看账单。取消续费后权益保留到本期结束；到期、欠费或未完成支付时使用 Free 权益。

返回支付成功页只打开用量面板。只有签名有效的 webhook 获取 Stripe 最新订阅、核对所有者、价格与已支付发票后，才更新权益。未配置 Stripe 时显示“在线支付尚未开通”，禁用购买，Free 仍可使用。支付处理代码和模拟测试已实现；真实支付闭环须在接入商户配置后另行验证。

初版不提供全量收费历史 UI、退款自动撤销额度、按比例额度赠送或自助对账工具。Portal 的套餐切换、按比例计费、取消与税务策略须由运营方明确配置；建议先仅开放取消，升级通过账期末切换，避免用户误解当期费用。

## 国内版

示例价为 Free ¥0、Plus ¥20、Pro ¥99，正式价格由部署配置决定。微信扫码一次购买 30 天，到期回到 Free，可再次购买。账户面板可恢复待支付订单并查单。扫码需要另一台设备展示二维码。

国内版 DeepSeek Flash 采用官方高峰价作为固定额度费率，沿用每美元 25 credits 的换算。每百万 Token 的普通输入、输出、缓存读取分别扣 7.5、30、0.15 credits。DeepSeek 没有单列缓存写入价，若适配器报告该类别，按未命中输入费率 7.5 结算。供应商低峰折扣不改变此固定额度费率。[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)

国内市场可配置支付宝网页收款。账户面板提供一次性购买 Plus 或 Pro AI 额度包，有效期 30 天。服务端确认交易后开始计算周期。未完成的单笔订单可继续付款或主动查询。
