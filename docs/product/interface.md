# 界面设计约定

更新：2026-11-14。

Folio 的主要任务是整理简历、按岗位生成版本和导出。界面参考 Linear 的层级与备忘录的文档布局，以中性色、少量边界和直接动作组织页面。工作台不放营销标语、欢迎长文、装饰性英文或 LIVE / NEW 标签。

## 入口

未登录展示独立落地页：产品名、简历工作台标题、一句功能说明、Google 登录，以及用现有 ResumeDocument 展示的虚构示例。不读取或初始化个人简历分区。

live 只在有效 session 下挂载工作台。demo 增加“试用示例”，由用户主动进入访客分区；同一标签页刷新可继续演示。配置读取失败显示重试，不自动降级。退出登录返回落地页，保留账户在当前浏览器的数据。

## 工作台

桌面为导航、对话、文档三栏，各自使用完整视口高度。对话列从顶部开始，由独立滚动的消息区和底部输入框组成；不保留跨栏页头、顶部工具条或当前简历卡片。手机从左侧图标导航切换对话与预览，不再添加横向切换条。

“导入简历”“润色简历”“按岗位定制”收进输入框底部的“＋ / 简历操作”弹层，当前简历在同一行显示并截断长名称。菜单打开不改变消息区高度，支持 Escape 与点击外部关闭。账户与演示状态只在侧栏。文档的标题、编辑和导出工具只占用文档列。

用户还没有个人简历（空库或仅有示例）且当前对话为空时，在输入框上方显示紧凑的“导入简历”入口，点击打开现有导入窗口，可粘贴原文或选择 PDF、DOCX、TXT、MD、Folio JSON。打开和取消不调用 Agent、不改写简历。开始对话后自动收起；已有个人简历时，新对话也不重复提示。此入口位于输入区域，不增加消息区顶部工具条，也不新增 onboarding 存储状态。

聊天正文、输入和更新明细统一 12px，使用足够的行高与深色文字。文档排版独立，不随聊天字号缩小。“本次草稿更新”保留，默认一行折叠，点击或键盘展开完整修改说明与关键词；待补充事实始终可见。

普通聊天修改与润色更新当前简历，不移动列表位置或增加条目；导入和按岗位定制才新增。继续修改定制稿仍保持同一身份与名称。

仅在影响操作或判断时显示状态：示例、生成中、保存失败、登录错误和事实缺口。存储位置放在账户设置中，不占据侧栏。

## 删除

整份简历、工作经历和重复副本清理共用确认组件。先呈现目标名称，默认聚焦“取消”；确认后才改变数据。Escape 与关闭只取消。整份删除与清理保留最近一次操作的当页撤销；工作经历确认删除后直接保存当前版本。

左侧最近简历、简历库和预览只从同一个集合派生。选择通过 ID 查找现有对象，过期 ID 不执行操作。`storage` 事件同步同浏览器其他标签页的变更，并清除过期命令、结果、删除请求和撤销快照。删除不能调用模型或新增版本。

## UX / DX / AX

| 决定           | UX                               | DX                                     | AX                                     |
| -------------- | -------------------------------- | -------------------------------------- | -------------------------------------- |
| 单一工作台入口 | 未登录不会误入无法生成的界面     | 配置与 session 统一决定挂载            | 页面状态与可用操作一致                 |
| 共用删除确认   | 避免误删，取消不变更             | 一套组件覆盖删除入口                   | 目标、取消、确认均有明确语义名称       |
| 原生折叠明细   | 默认节省空间，按需查看           | 不新增展开状态或消息仓库               | summary 支持键盘，明细仍存在于文档结构 |
| 同一简历集合   | 删除立即反映到导航和预览         | 不维护第二份侧栏缓存                   | 不出现可点击的失效对象                 |
| 共享文档渲染器 | 示例、预览与打印一致             | 不新增示例数据结构或重复模板           | 各处读取相同结构化简历                 |
| 少量设计变量   | 字号与层级稳定                   | 删除废弃样式，避免逐屏叠加覆盖         | 状态和操作不依赖装饰文字               |
| 对话完整高度   | 留出更多阅读空间，输入不遮住消息 | 视口高度与单一滚动容器替代页头高度计算 | 消息、输入、工具弹层有明确独立区域     |

新增功能先检查能否纳入这些布局和数据边界。必要错误、事实缺口和示例标识不能为了减少文字而隐藏。
