# 界面设计约定

更新：2026-11-14。

Folio 的主要任务是整理简历、按岗位生成版本和导出。界面参考 Linear 的层级与备忘录的文档布局，以中性色、少量边界和直接动作组织页面。工作台不放营销标语、欢迎长文、装饰性英文或 LIVE / NEW 标签。

## 入口

未登录落地页面向“已有简历、需要按岗位调整”的求职者。首屏说明导入已有简历、粘贴岗位描述、生成独立投递版本及 PDF 导出；“开始定制简历”在国内站打开登录方式弹窗，展示已配置的选项。微信为主入口，GitHub 和邮箱验证码并列可见。邮箱在同一弹窗内切换表单，支持返回、有效期倒计时和重发。微信二维码在弹窗中加载，也可打开微信授权页。关闭弹窗恢复触发按钮的焦点。只有 Google 登录的海外配置直接进入授权。静态“查看定制示例”在配置加载前也可用。不读取或初始化个人简历分区。

示例明确标注虚构、非实时生成：并列说明原简历、岗位要求、已有事实的重排与待补充信息，右侧用同一个 ResumeDocument 呈现重排结果，不给缺失技能补造经历。后续展示导入 → 岗位定制 → 核对导出的三步流程、对话编辑/版本/排版价值、免费额度和数据保存、常见问题。使用原生链接导航和跳到正文入口；手机端纵向排列案例，保留示例标识与事实缺口。

首页正文在服务端渲染，供搜索引擎与 AI 检索读取；主按钮“开始定制简历”也在服务端输出，配置读取完成后才可点击，未配置登录时不显示。服务端同时读取会话：已登录访客直接进入工作台（配置完成前显示中性加载状态），不闪现落地页；客户端会话钩子只负责登录/退出后的切换。标题、description、canonical、分享卡片及结构化数据与可见内容一致，robots/sitemap/llms.txt 仅说明公开页面和实际能力，不承诺搜索排名、AI 引用或特殊展示。robots 排除 API 抓取，不能替代访问控制。

登录、试用与查看示例的点击，以及落地页实际展示的访问，只发送匿名事件名和可选的 UTM 来源到 Cloudflare Analytics Engine，不包含简历、账户或设备标识；页面浏览同时使用 Cloudflare Web Analytics。两者都不使用营销 Cookie 或第三方脚本。

免费说明使用按实际用量消耗、每月重置的额度描述，不换算固定简历份数；当前额度和可用套餐以账户页面为准，不硬编码在线支付状态。AI 内容须由用户投递前核对，不作零编造保证。数据说明同时覆盖浏览器本地简历库、无跨设备同步、AI 服务传输与服务端请求记录/结果留存；本地删除不代表服务端记录同步删除，不以“本地保存”暗示内容不出设备。

live 只在有效 session 下挂载工作台。demo 增加“试用示例”，由用户主动进入访客分区；同一标签页刷新可继续演示。配置读取失败显示重试，不自动降级。退出登录返回落地页，保留账户在当前浏览器的数据。

## 工作台

桌面为导航、对话、文档三栏，各自使用完整视口高度。对话列从顶部开始，由独立滚动的消息区和底部输入框组成；不保留跨栏页头、顶部工具条或当前简历卡片。手机从左侧图标导航切换对话与预览，不再添加横向切换条。

“导入简历”“润色简历”“按岗位定制”保留在输入框底部的“＋ / 简历操作”弹层，当前简历在同一行显示并截断长名称。有简历时，在发送按钮旁常驻“按 JD 定制”，替换原“Enter 发送”提示，不新增工具行；生成期间禁用，空库先引导导入。输入框占位文字提示可直接粘贴岗位描述（JD）。定制窗口说明基于当前候选人的简历库生成独立版本、保留原简历；打开、取消和空输入不发起生成。菜单打开不改变消息区高度，支持 Escape 与点击外部关闭。账户与演示状态只在侧栏。文档的标题、编辑和导出工具只占用文档列。

新对话在消息区内居中展示淡色 HTML 功能引导：导入已有简历、用对话修改简历、按 JD 定制投递版本。每项用小型文档、对话和 JD 图示说明输入与结果，文字保持可读对比度。导入和定制复用已有窗口；修改入口只在输入为空时填入可编辑的示例要求并聚焦输入，不自动发送、不覆盖未发送内容。空库时禁用修改和定制，先导入；仅有示例时仍可试用这些操作。已有个人简历时导入项改为“导入另一份简历”。引导只读取 assistant-ui 空线程/运行状态，开始对话后收起，新对话再次显示；恢复历史消息时不显示。不增加顶部工具条、额外消息或 onboarding 存储状态。短屏只滚动消息区，输入框保持可见。

聊天正文、输入和更新明细统一 12px，使用足够的行高与深色文字。文档排版独立，不随聊天字号缩小。“本次草稿更新”保留，默认一行折叠，点击或键盘展开完整修改说明与关键词；待补充事实始终可见。切回已有岗位稿或刷新后，从它的对话恢复已保存的核对卡。

模板页提供四套当前内容的缩略图，以及简介、技能、工作要点和密度四个原生选择框。局部设置保存在当前简历，点击“查看简历”返回完整预览；选择其他模板使用其预设，重新选当前模板保留局部设置。恢复模板排版不改正文。模板和局部设置不占用聊天上方空间；所有选择框有明确名称，缩略图中的重复文档从无障碍树隐藏。

普通聊天修改与润色更新当前简历，不移动列表位置或增加条目；导入和按岗位定制才新增。继续修改定制稿仍保持同一身份与名称。

仅在影响操作或判断时显示状态：示例、生成中、保存失败、登录错误和事实缺口。存储位置放在账户设置中，不占据侧栏。

## 删除

整份简历、工作经历和重复副本清理共用确认组件。先呈现目标名称，默认聚焦“取消”；确认后才改变数据。Escape 与关闭只取消。整份删除与清理保留最近一次操作的当页撤销；工作经历确认删除后直接保存当前版本。

左侧最近简历、简历库和预览只从同一个集合派生。选择通过 ID 查找现有对象，过期 ID 不执行操作。`storage` 事件同步同浏览器其他标签页的变更，并清除过期命令、结果、删除请求和撤销快照。删除不能调用模型或新增版本。

## UX / DX / AX

| 决定           | UX                               | DX                                     | AX                                     |
| -------------- | -------------------------------- | -------------------------------------- | -------------------------------------- |
| 单一工作台入口 | 未登录不会误入无法生成的界面     | 配置与 session 统一决定挂载            | 页面状态与可用操作一致                 |
| 共用删除确认   | 避免误删，取消不变更             | 一套组件覆盖删除入口                   | 目标、取消、确认均有明确语义名称       |
| 原生折叠明细   | 默认节省空间，按需查看           | 不新增展开状态或消息仓库               | summary 支持键盘，明细仍存在于文档结构 |
| 同一简历集合   | 删除立即反映到导航和预览         | 不维护第二份侧栏缓存                   | 不出现可点击的失效对象                 |
| 共享文档渲染器 | 示例、预览与打印一致             | 不新增示例数据结构或重复模板           | 各处读取相同结构化简历                 |
| 少量设计变量   | 字号与层级稳定                   | 删除废弃样式，避免逐屏叠加覆盖         | 状态和操作不依赖装饰文字               |
| 对话完整高度   | 留出更多阅读空间，输入不遮住消息 | 视口高度与单一滚动容器替代页头高度计算 | 消息、输入、工具弹层有明确独立区域     |

新增功能先检查能否纳入这些布局和数据边界。必要错误、事实缺口和示例标识不能为了减少文字而隐藏。

### 微信小程序

原生小程序对齐上述 CN 手机端视觉规则，保留微信系统导航栏。图标侧栏进入对话、预览、简历库、模板和历史；账户入口在底部。欢迎卡片、12px 消息、底部输入框与“＋”菜单采用相同设计参数。原生预览、库缩略图和模板列表共用一份 WXML 文档模板，局部排版复用领域规则。两端在对话区引导导入第一份 Word（DOCX）或 PDF，支持核对与粘贴原文；JSON 仅作为折叠的备份恢复入口。Web 在浏览器提取，小程序上传至鉴权服务端临时提取，选择文件前明确告知，不保存原附件，确认整理后才调用模型。小程序仍不提供 PDF 导出；链接呈现为文字，原始 HTML 与媒体不进入 rich-text。

### 命令与恢复

网页上的“整理为简历”和“生成定制草稿”只决定这一次提交的意图。导入原文即使含有“工作职责”，仍按新简历处理，只提交本次原文与空白简历上下文。完成、失败或取消后，下一条自由输入重新判断意图。撤销整份删除同时恢复原先预览的简历和对话。润色期间若另一标签页已修改同一份简历，保留手工修改，在对话中提示重新核对。

小程序空库可以直接输入经历。导入或定制完成后，下一条普通修改作用于刚选中的稿件。请求被明确拒绝时，输入框恢复原文供修改；网络中断时保留原请求供恢复。切换身份会清除上一空间未提交的输入和编辑草稿。各入口的触发条件见[状态机清单](../harness/state-machines.md)。

停止持久任务时，网页等待服务端回执。回执未确认会在当前对话显示“重试停止”，重试使用原请求标识。小程序恢复轻量任务时，服务端仍有预留则保留原请求供查询；任务已结束且无可恢复结果时，原文回到输入框供核对后重发。
