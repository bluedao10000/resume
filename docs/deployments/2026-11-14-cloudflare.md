## 需要账号所有者完成的 Google 设置

实际访问 Google 授权页时，Google 返回 **Error 400: redirect_uri_mismatch**。Cloudflare 域名与 HTTPS 已经正常，此错误需要在该 Google OAuth client 的配置中修复。

后续状态：用户追加 Google 配置后重新检查，Google 授权页正常，不再出现 redirect_uri_mismatch 或 invalid_client。下述步骤保留作为其他环境的配置参考。

1. 打开 Google Cloud Console，选择对应 OAuth client 所属项目。
2. 进入 **Google Auth Platform → Clients**，或 **APIs & Services → Credentials**。
3. 打开与 `.env` 中 `GOOGLE_CLIENT_ID` 对应的 Web application 客户端。
4. 在 **Authorized JavaScript origins** 添加 `https://r.story2u.xyz`。
5. 在 **Authorized redirect URIs** 添加 `https://r.story2u.xyz/api/auth/callback/google`，无末尾斜杠。
6. 保存，待配置生效后重新打开应用发起登录。若应用仍处于 Testing 状态，确认登录账号已列入 Audience 的测试用户。

若只是追加允许的 origin / redirect URI，不需要更改应用密钥或重新部署。若换了 OAuth client，需更新 `.env` 中的 client ID / secret 并执行 `npm run deploy`。
