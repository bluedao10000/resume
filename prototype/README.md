# Folio 交互原型

原型就是仓库中可运行的 TanStack Start 应用，避免独立静态稿与源码出现行为偏差。启动方式见根 README。

## 视觉方向

中性色、清晰边界和直接操作。未登录有独立落地页，以一句功能说明和真实文档组件展示产品。工作台左栏是导航，中间是对话，右栏是简历；不放标语、欢迎长文和装饰性标签。文档保留独立的纸面排版。

桌面三栏均占满视口高度；消息区顶部没有标题、工具条或来源卡片。工具从输入框“＋”打开。小屏压缩侧栏，手机在侧栏切换对话与预览。模板中心和简历库保持同一导航。聊天使用统一小字号，更新卡片默认折叠明细，事实缺口始终可见。完整约定见 [界面设计](../docs/product/interface.md)。

## 五分钟演示

1. 首页展示落地页。demo 点击“试用示例”；live 使用 Google 登录。进入后查看“林知夏”示例，从输入框“＋”菜单点击“润色简历”，观察当前简历原位更新、数量不增加，展开“本次草稿更新”。
2. 从输入框“＋”菜单点击“导入简历”，在弹窗“填入示例”并整理。确认预览成为“陈亦舟”，示例公司的经历与教育不混入。
3. 点击右侧“编辑内容”，填写经历和教育。删除工作经历时先取消，确认原文仍在，再确认删除。
4. 从输入框“＋”菜单点击“按岗位定制”，填入示例 JD 并生成。观察新增独立定制稿，继续聊天修改时数量不再增加；系统选择更匹配的简历来源，标出 `B2B SaaS / 英语沟通` 等缺口，不编造经历。
5. 打开“我的简历库”，按姓名搜索，选择此前版本。
6. 在模板中心切换“极简留白”，确认文案保持一致。
7. 点击导出，以浏览器打印面板保存 PDF；导出 JSON，再用导入窗口重新导入验证可移植性。
8. 删除整份简历，确认前数据不变；确认后侧栏立即移除，可撤销。删空后刷新仍保持空库。打开两个标签页，在其中一个删除，另一个同步。
9. 刷新，确认简历保留，对话重新开始。退出账户返回落地页。

## 页面与关键状态

| 页面/组件    | 正常状态                         | 其他状态                          |
| ------------ | -------------------------------- | --------------------------------- |
| 落地页       | 功能说明、Google 登录、产品示例  | 登录错误、配置失败、demo 显式试用 |
| Agent 工作台 | 全高消息区、输入框操作菜单、预览 | 生成中、停止、接口错误、缺口提示  |
| 简历库       | 卡片列表、关键词搜索             | 搜索无结果、本机存储失败提示      |
| 简历画布     | 预览、直接编辑、保存状态         | 生成时禁止直接编辑；手机独立视图  |
| 模板中心     | 经典叙事、极简留白               | 当前模板标记；生成期间禁止切换    |
| 导入         | 粘贴、TXT/MD、JSON               | 空输入、文件过大、结构错误        |
| JD 定制      | 岗位原文                         | 未覆盖要求仅提示补充              |
| 登录         | Google 跳转入口                  | 凭据未配置、登录错误、退出        |
| 导出         | 打印/PDF、JSON                   | 本地下载；不依赖服务端渲染        |

## 原型与真实服务的区别

页面是实际产品源码，基础 UI 采用 Astryx。默认 Agent 采用规则处理；模型接入须配置并切换 live。聊天展示使用 assistant-ui，不模拟独立消息数组。身份使用 Better Auth；本机数据不会因登录自动变成云端同步。

界面截图存放在本目录 `screenshots/`；它们只记录相应测试时刻，功能是否可用以源码和自动化测试为准。
